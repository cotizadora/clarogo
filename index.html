GoExt Recomendado

          
ClaroGo! funciona mucho mejor con GoExt. Es la extensión para Edge o Chrome que trae los datos de Genesys a tu planilla, revisa la deuda, usa el Rutificador, abre WhatsApp y llena los formularios.

        

      

      ⬇ Descargar instalador de GoExt
      
Ábrelo con doble clic. Tarda unos segundos, se cierra solo y deja en tu escritorio el acceso Actualizar GoExt. Desde ahí GoExt se actualiza sola cada 2 horas.

      

        
🛡️ Alternativa: si el computador no te deja abrir el instalador (Control inteligente de aplicaciones)

        
Windows 11 puede bloquear el instalador porque no tiene firma digital. No desactives esa protección. Descarga GoExt directamente desde aquí, sin ejecutar nada:

        ⬇ Descargar GoExt en .zip
        
    
          
  1. Abre la carpeta Descargas, haz clic derecho en goext.zip → Extraer todo → Extraer. Queda una carpeta llamada goext.
    2. 
          
  2. En edge://extensions (o chrome://extensions) activa Modo para desarrolladores.
    3. 
          
  3. Presiona Cargar desempaquetada y elige la carpeta Descargas → goext. No la borres ni la muevas después.
    4. 
        

        
Para actualizar: cuando GoExt avise que hay una versión nueva, presiona Actualizar ahora. Se abre una página con el botón Descargar GoExt: baja goext.zip a Descargas y abre la carpeta con el archivo marcado. Haz clic derecho → Extraer todo → Extraer → Reemplazar los archivos en el destino. La página activa la versión nueva sola. (Desde la versión 1.52.0 de GoExt. Si tienes una más antigua, actualiza esta vez descargando el .zip de arriba y extrayéndolo en la misma carpeta goext.)

      

      

        
Instalar (solo la primera vez)
    
          
  1. Abre el instalador con doble clic. Si Windows pregunta, elige Más información y luego Ejecutar de todas formas.
    2. 
          
  2. Escribe en la barra de direcciones y presiona Enter:
            
    edge://extensions
    
            En Chrome: chrome://extensions
    3. 
          
  3. Activa Modo para desarrolladores.
    4. 
          
  4. Presiona Cargar desempaquetada, pega esta carpeta y elige Seleccionar carpeta:
            
    Documentos\ClaroGo\extension
    5. 
        

        
Actualizar con un clic
    
          
  1. GoExt se actualiza sola cada 2 horas. Al abrir el navegador ya parte con la versión nueva; si estaba abierto, aparece el aviso "GoExt está lista: haz clic para activarla".
    2. 
          
  2. Si quieres hacerlo al tiro: cuando GoExt avise una versión nueva, abre su ícono rojo y presiona ⬇ Actualizar.
    3. 
          
  3. La primera vez el navegador pregunta si abre el actualizador: marca Permitir siempre y presiona Abrir. También puedes usar Actualizar GoExt del escritorio.
    4. 
        
Ver la guía de instalación completa ↗

MuteReal

        
Programa para Windows que muestra en todo momento si tu micrófono está de verdad silenciado. Así evitas que el cliente escuche lo que no debe.

      

    

    ⬇ Descargar MuteReal
    
Programa para Windows · No necesita instalación ni permisos de administrador · Hecho por Eduardo Pérez para ClaroGo!

    

      
¿Qué hace?
    
        
  • Deja un indicador flotante siempre visible, encima de las demás ventanas.
    • 
        
  • Muestra el estado real del micrófono de Windows: silenciado o activo.
    • 
        
  • Con un clic en el indicador silencias o activas el micrófono.
    • 
      

      
Cómo usarlo
    
        
  1. Descárgalo y ábrelo con doble clic.
    2. 
        
  2. Si Windows avisa "Windows protegió su PC", presiona Más información y luego Ejecutar de todas formas.
    3. 
        
  3. Arrastra el indicador donde te acomode. Con clic derecho ves sus opciones, por ejemplo iniciar con Windows.
    4.

Conexión con GitHub: sin conectar
      
Este navegador puede publicar el stock. 

      

        
En el computador de Eduardo no hace falta esta clave: usa el ícono Actualizar stock ClaroGo del escritorio, que publica con la sesión de GitHub del equipo.
Para publicar desde esta página en otro computador, se hace una sola vez. Después basta con elegir el Excel y presionar Publicar.

        
    
          
  1. Con la cuenta de GitHub cotizadora abre Crear clave en GitHub (llega con el nombre y el permiso ya puestos).
    2. 
          
  2. Nombre: ClaroGo stock. Vencimiento: el que prefieras.
    3. 
          
  3. En Repository access elige Only select repositories y marca clarogo.
    4. 
          
  4. En Permissions agrega Contents con acceso Read and write.
    5. 
          
  5. Presiona Generate token, copia la clave y pégala aquí.
    6. 
        

        

        La clave queda guardada solo en este navegador y no se borra al limpiar la caché. No la compartas. Si se filtra, bórrala en GitHub y crea otra.
      

    

    
 El botón Actualizar stock deja de verse aquí hasta volver a entrar con la clave.

    
Otras formas de cargar
      
Pega columnas copiadas de Excel (SKU, Marca, Modelo, Stock, Pie y Cuotas con sus títulos) y presiona Revisar. Si no tienes la conexión con GitHub, descarga stock.csv y súbelo a la carpeta datos.

      
      

        
        
        Abrir GitHub para subirlo
